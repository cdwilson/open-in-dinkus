# Sample document

Use this file to try out **Open in Dinkus**:

- Right-click this file in the Explorer and choose **Open in Dinkus**.
- Right-click anywhere in this editor and choose **Open in Dinkus**.
- Click the Dinkus button (three asterisks) at the top right of this editor.
- Right-click this editor's tab and choose **Open in Dinkus**.

Edit this text without saving, then open it in Dinkus: the change should be
saved first and appear in Dinkus.
